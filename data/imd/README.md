# Index of Multiple Deprivation (IMD) Data

This directory contains deprivation data used in the ASC Neighbourhood Intelligence project.

The Index of Multiple Deprivation (IMD) was integrated with neighbourhood-level Adult Social Care referral data to investigate the relationship between deprivation and service demand.

## Purpose

The dataset supports:

- Mapping neighbourhoods to deprivation quintiles
- Comparing ASC referral rates across deprivation groups
- Identifying inequalities in Adult Social Care demand
- Supporting neighbourhood-level strategic analysis

## Key Field

`IMD_Quintile` represents the deprivation grouping used in the Power BI analysis.

## Analytical Use

IMD data was joined to the integrated neighbourhood dataset using geographic identifiers.

The analysis found that the most deprived areas had approximately **1.34× the referral rate of the least deprived areas** within the portfolio dataset.

This relationship is treated as an analytical association and should not be interpreted as evidence that deprivation directly causes higher Adult Social Care demand.

## Data Use

The data is included for analytical and portfolio demonstration purposes. Area-level deprivation measures should not be interpreted as representing the circumstances of every individual living within an area.
