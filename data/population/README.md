# ONS Population Data

This directory contains population data used in the ASC Neighbourhood Intelligence project.

Population data was used to create population-adjusted Adult Social Care referral rates, allowing neighbourhood demand to be compared more fairly than using raw referral totals alone.

## Data Source

The project used ONS LSOA 2021 population data, including population information from the:

- Mid-2022 LSOA 2021 dataset
- Mid-2023 LSOA 2021 dataset
- Mid-2024 LSOA 2021 dataset

## Purpose

The population dataset supports:

- LSOA-level population analysis
- Adult Social Care demand normalisation
- Neighbourhood comparison
- Population-adjusted referral-rate calculations

## Key Analytical Measure

The project calculates:

`Referral_Rate_per_1000 = (ASC_Referrals / Population_65_plus) × 1000`

This provides a more meaningful comparison between neighbourhoods with different population sizes.

## Recorded Result

The highest recorded referral rate in the portfolio analysis was:

**285.7 referrals per 1,000**

for **Southampton 001A**.

## Data Use

The population data is used for analytical and portfolio demonstration purposes. Source data and population estimates should be checked against the latest official ONS releases before use in operational decision-making.
