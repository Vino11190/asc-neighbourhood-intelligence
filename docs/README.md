# ASC Neighbourhood Intelligence — Documentation

This folder contains the complete project and technical documentation for the ASC Neighbourhood Intelligence portfolio project.

The documentation covers:

- Project objectives and business problem
- Data sources
- Python data preparation and integration
- Population-adjusted referral-rate analysis
- IMD deprivation analysis
- Power BI development
- Demand and forecasting analysis
- Strategic insights
- Technical implementation
- Data governance and limitations
- Portfolio outcomes

This is an independent portfolio project and should not be interpreted as an operational council system.
